Systematic-prefix sweep, LightBeam LT fountain code
===================================================

Tool: tools/diag/prefix-experiment.ts
Metric: frames the SENDER must display per source block (sent/K). This is the
quantity that maps directly to transfer time on screen. 3 trials per cell,
blockSize = 512 B, robust soliton (c = 0.03, delta = 0.5), dense fallback 256.

Reproduce (one run per column; each prints its own table, merged here):
  for k in 64 128 512 1024; do LB_K=$k npx tsx tools/diag/prefix-experiment.ts; done

"50%+burst" = 50% per-frame survival probability plus bursts of 40 consecutive
lost frames every 60 frames (a hand crossing the camera, an autofocus hunt).

CONCLUSION
----------
prefix/K = 0.10 is at or near the best column for every k and every channel,
and is never worse than pure LT. A full systematic prefix (1.00) is optimal ONLY
on a perfect channel, and costs 25-30% more screen time once frames are being
lost, because the missed systematic frames leave specific holes that a
uniformly-covering LT frame is bad at filling.

Shipped default: SYSTEMATIC_PREFIX_FRACTION = 0.1 (packages/core/src/fountain/lt.ts).
